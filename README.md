# Customer Retention & Sales Optimization Analysis

## Objective
Analyze retail transaction data to understand customer retention, revenue trends, and customer lifetime value.

## Tools Used
- SQL
- Excel
- Power Query

## Key Analysis
- Top customers by revenue
- Repeat vs one-time customers
- Monthly revenue growth
- Customer lifetime value (CLV)

## Output
- SQL queries for analysis
- Excel dashboards
- Summary report with insights

## Notes
This project was completed as part of a Certified Data Analyst capstone assignment.
